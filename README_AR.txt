NUVEX NUMBERS — مشروع بوت سوق الأرقام

المزايا:
- بوت واحد مستقل باسم NUVEX NUMBERS، وليس نظام بوتات فرعية.
- ترحيب مختصر وقسم منفصل لمعرفة البوت.
- عرض الأرقام للبيع مع تحديد السعر والعملة.
- مراجعة الإدارة للإعلانات قبل نشرها.
- تصفح الأرقام وطلب شرائها.
- محفظة داخلية: طلب إيداع بإثبات، وطلب سحب.
- الإدارة توافق/ترفض الإعلانات والإيداعات والسحوبات.
- الطلبات، سجل العمليات، الدعم، ولوحة إدارة مختصرة.
- قاعدة بيانات SQLite دائمة في ملف nuvex.db.

التشغيل على Termux:
1) فك ضغط الملف.
2) افتح Termux وانتقل إلى مجلد المشروع:
   cd /مسار/NUVEX_NUMBERS_BOT
3) ثبّت بايثون إن لم يكن مثبتاً:
   pkg update && pkg install python -y
4) ثبّت المكتبات:
   pip install -r requirements.txt
5) انسخ env.example إلى .env:
   cp .env.example .env
6) افتح .env وعدّل:
   BOT_TOKEN = توكن @BotFather
   ADMIN_IDS = آيدي حسابك الشخصي (ليس آيدي البوت)
7) شغّل:
   python main.py

أوامر:
- /start بدء البوت
- /id عرض آيدي حسابك
- /admin لوحة الإدارة للمشرفين
- /contact إرسال رسالة للدعم

مهم:
- لا ترسل توكن البوت لأي شخص ولا تضعه في صور أو قنوات عامة.
- أضف مشرفاً واحداً على الأقل في ADMIN_IDS.
- القناة المعرفة في ACTIVATION_CHANNEL محفوظة في الإعدادات حالياً؛ يلزم إضافة وظائف النشر للقناة حسب آلية التفعيلات التي ستعتمدها.
- العمولة الافتراضية 5% ويمكن تغييرها في .env.
- العملة المختارة لكل إعلان/عملية محفوظة كسجل، لكن الرصيد المعروض حالياً إجمالي غير مفصول حسب العملة؛ قبل الإطلاق التجاري يجب فصل الأرصدة حسب العملة أو تثبيت عملة واحدة.
- الدفع والسحب يدويان ويحتاجان مراجعة فعلية من الإدارة.
- لا تستخدم المنصة لبيع أرقام لا تملك حق التصرف بها أو لتجاوز حماية الحسابات أو انتحال الهوية.
